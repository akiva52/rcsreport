# Roselle Report Builder

PCNA & Capital Reserve Advisory report generator for Roselle Creative Solutions.

## Setup
1. Run `npm install`
2. Run `npm run dev` to start locally
3. Deploy to Vercel by connecting this repo

## How to deploy
1. Push this folder to a GitHub repo
2. Go to vercel.com and import the repo
3. Vercel auto-detects Vite — just hit Deploy
